ARTIVITY 1.2 — Комплексы тренировок и тоннаж

Содержимое архива копировать в корень C:\Users\100nout\artivity

Изменения:
- Комплексы: список, собственное название, тип, добавление уже созданных и новых упражнений, запись всех упражнений одного комплекса за выбранную дату, общая история, повтор/редактирование/удаление через меню ⋮.
- Существующие упражнения и их история остаются. Внутри упражнения показаны тоннаж за всё время и компактная история с меню ⋮.
- На главном экране в карточке «Твоя неделя» вместо дубля Streak показан тоннаж за календарную неделю.
- В «Мой прогресс» тоннаж: текущая календарная неделя, месяц, год, всё время.
- SQLite v6 добавляет таблицы комплексов и ссылку на комплексную сессию; старые данные не очищает.

Правило подсчёта: сумма вес_кг × повторения по всем подходам, где оба поля заполнены.
Для двух гантелей вводи суммарный вес обеих. Подходы без веса (кардио, собственный вес) не увеличивают тоннаж.
Сводные totals считаются по workout_sets, не по сумме комплексов и упражнений, поэтому нет двойного учёта.

Установка:
1) Сохрани текущую версию на GitHub до изменений, если есть незакоммиченная работа.
2) PowerShell в папке artivity:
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\artivity-tonnage-complexes-v1.2.zip" -DestinationPath . -Force
3) npx expo start -c
   (запусти один раз для генерации типов нового маршрута /complex/[id]).
4) Останови Ctrl+C, затем npx tsc --noEmit.
5) При отсутствии ошибок запускай npx expo start.

Проверки:
- Записи в старых одиночных упражнениях должны сохраниться.
- Создай комплекс «День спины», добавь два упражнения, запиши подходы и дату.
- Убедись, что тоннаж комплекса = сумма вес × повторы его упражнений.
- Убедись, что оба упражнения видны в своей истории и в календаре.
- Убедись, что тоннаж в «Сегодня» и «Прогресс» обновился после возвращения на вкладку.
- Повтори/измени/удали занятие комплекса через ⋮: сумма пересчитывается.
- Проверь сохранение после закрытия и повторного запуска приложения.

Для установленного APK изменения исходников не появятся автоматически: после проверки в Expo Go нужна новая preview EAS APK с тем же android.package и ключом подписи. Обновляй поверх, не удаляя приложение, иначе его SQLite-данные могут потеряться.
