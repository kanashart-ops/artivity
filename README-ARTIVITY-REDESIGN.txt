Artivity 0.9 — реальный современный дизайн для Expo SDK 58

1. Перед установкой желательно сохранить текущий прогресс на Git.
2. Из корня проекта artivity:
   npx expo install react-native-svg expo-linear-gradient
3. Распакуйте этот архив в корень проекта с заменой файлов.
4. Выполните:
   node scripts/apply-artivity-design.mjs
   npx tsc --noEmit
   npx expo start -c

Архив содержит новый интерфейс Сегодня и Интервалы, реальную статистику Прогресс,
обновлённую навигацию, два новых визуальных компонента.
Существующая база SQLite и тренировочный журнал не удаляются.

Если нужно откатить дизайн до пуша, используйте git restore для изменённых файлов.
